# Правила роботи з Git

- Основна робоча гілка проєкту — `develop`.
- Усі коміти потрібно створювати з повідомленнями українською мовою.
- Якщо для виконання завдання потрібна окрема гілка, її необхідно створювати від актуальної гілки `develop`.
- Перед створенням нової гілки потрібно перейти на `develop` та оновити її з віддаленого репозиторію.
- Не вносити робочі зміни безпосередньо до `main`.
